# Escenarios de práctica

Los archivos de esta carpeta describen datos ficticios y no son cuentas reales ni registros importados. Implementa las tablas y el importador de fixtures aislados en las etapas correspondientes. No cargues datos personales, contraseñas ni respuestas que finjan una extracción real. Los doce soportes autorizados viven en soportes/; sus hashes se conservan.
